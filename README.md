# 会记 · 商务会议纪要

本地运行的会议纪要工具，支持文本输入和录音本地转写，按八项固定大纲整理，逐条保留原文依据，经人工确认后导出。

当前为 **0.2.4 版本**。已接入部门邀请码注册与登录、录音上传、本地 ASR、独立说话人处理接口、回听及音频保留策略；完整 MVP 仍需真实样本、说话人模型和长会议等功能验收。

注册登录：在本机 `.env` 中设置 `AUTH_REQUIRED=true` 和不少于 16 字符的随机 `REGISTRATION_INVITE`，重启后生效。云端入口为 `cloud_app.py`，强制登录。邀请码通过私密渠道发给同事；不要放进代码仓库。账号使用 3–32 位英文、数字等字符，密码至少 12 字符，登录会话 12 小时后失效。所有账号共用会议库，当前不含找回密码、管理员角色和邮箱验证。

云端 MVP 按用户要求暂用 SQLite 和临时磁盘：账号、会议、录音及模型在服务器重建时可能全部丢失，不适合长期归档。云端录音会上传到服务器处理，不是在浏览者电脑上处理。部署使用 Python 3.12、入口 `cloud_app.py`，在平台 Secrets 中配置 `REGISTRATION_INVITE`。初次使用录音时，登录后点击“准备云端转写模型”；默认使用 small / cpu / int8。部署不上传本机 `data/`、录音、密钥或模型。

鼠标移到侧栏历史会议标题所在行时，右侧显示“✕”删除按钮，无需先打开会议即可删除。键盘聚焦该行时也显示，触屏设备常显；点击后仍需确认，再移入回收站。

打开会议后，点击顶部“删除会议”，确认后将整场会议及全部历史版本移入侧栏“回收站”，可随时恢复。录音仍按原保留策略清理，恢复会议不会找回已清理的录音；已导出的文件不受影响。本版本不提供永久清空回收站。

每个版本的主要变化、验证结果及限制见 [版本更新日志](CHANGELOG.md)。

## 现在怎么用

本项目已在当前电脑创建 `.venv` 并安装依赖。在项目目录的 PowerShell 中运行：

```powershell
.\start.ps1
```

如果本机脚本执行策略不允许执行 `.ps1`，直接运行以下命令，无需修改系统策略：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

然后打开 [本地页面](http://127.0.0.1:8501)。服务默认只允许本机访问；此阶段没有手机远程访问配置。

1. 点击侧栏“体验虚构示例”，无需 API 即可查看完整的八节纪要。
2. 点击“查看原文”核对引用，编辑内容、分类或详细字段。需要删除的错误条目可以删除，旧修订保留。
3. 逐节审核，对商务条件、我方承诺、下一步动作逐条确认，并核对三个类别是否遗漏。未知信息允许明确确认保留未知状态。
4. 点击“保存为已确认版本”，下载 Markdown、JSON、会议 CSV 和行动项 CSV。
5. 也可以新建会议、粘贴文本并保存原文，通过“补充遗漏内容”手工整理。演示数据不会套用到你的文本上。

表单内编辑需要点击相应“保存”按钮才会写入磁盘；尚未提交的输入在刷新后可能丢失。保存后的草稿和审核状态可从侧栏历史或当前 URL 恢复。

## 后续配置 DeepSeek

你提供 API 和样本后再进行真实联调。目前没有真实 DeepSeek 调用，也没有产生 API 费用。本地音频转写不需要 DeepSeek key。

将 `.env.example` 复制成 `.env`，只在本机填写：

```dotenv
DEEPSEEK_API_KEY=在本机填写
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=当前可用的模型ID
DATA_DIR=data
```

不要提交或在聊天中粘贴真实密钥。模型 ID 参考 [DeepSeek 官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)，填写后重启应用。

每场会议须在页面勾选允许向 DeepSeek 发送文本。客户端发送原文、用户填写的元信息和说话人映射，执行 JSON 与逐字证据校验。服务端错误、限流及格式错误有有限重试，失败保留输入和已有修订。

引用精确匹配只能验证“这句话存在于原文”，不能证明模型的归纳语义正确；内容、归属、否定和条件仍需人工核对。未提供真实黄金样本前，不宣称抽取准确率或召回率达标。

费用估算使用 `.env.example` 中可选的输入/输出单价配置。未填单价时显示费用未知，不默认为免费；缓存、计价策略及实际账单以供应商为准。50 元为提醒预算，不是扣费硬上限。

## 已实现与边界

| 已实现 | 当前限制或后续工作 |
|---|---|
| 粘贴文本、UTF-8 TXT、行内说话人和时间戳解析 | 并未认证所有腾讯/飞书格式；无法识别的行按原文保留 |
| 固定八节及分类型事实字段、严格 Schema | 元信息及参会人身份主要由用户填写/确认 |
| 逐条原文定位、人工修改、增删和分类；有录音时按证据时间回听 | 无录音的纯文本不能回听；没有 LLM 自动术语纠错 |
| m4a / mp3 / wav 上传、本地 faster-whisper 转写、行业初始提示词 | 单文件最多 500 MB / 120 分钟，实际速度依赖设备；合成语音冒烟已通过，真实会议精度待验收 |
| 本地 pyannote 分离接口、匿名标签、人工归属修正 | 未安装 pyannote 及受访问条件限制的模型，尚未验证真实分离；缺失/失败时保留转写并标记待核对 |
| DeepSeek 客户端、错误重试、模拟响应测试 | 没有真实密钥联调；单场上限 12,000 字符 / 300 段，不截断 |
| 后端审核门禁、内容指纹校验、已确认历史保护 | 编辑后保守地使全场审核失效；未做多人并发协作 |
| SQLite 草稿/历史、中文关键词搜索、音频保留清理 | 无自动备份恢复、日期范围过滤；应用关闭期间不执行到期清理 |
| JSON、Markdown、两张 CSV | 不自动写入飞书；CSV 已处理公式前缀和换行转义 |
| CER 及基于人工匹配的抽取指标计分 | 无真实黄金集、实体专项计分和性能成本实测 |

后续顺序：真实样本与 API 联调 / 说话人模型准备 → 热词纠错 → 长会议合并 → 备份恢复 → 完整验收。无需准备云服务器、飞书 API 或云 ASR key。

## 使用本地录音

当前电脑已安装音频依赖，并下载 `small` 模型到 `data/models/`。新建会议时选择“录音文件”，上传后保存，再点击“开始本地转写”。音频不会发往 DeepSeek；是否将转写文字发送云端仍由单独的勾选控制。

在其他电脑上先运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-audio.txt
.\.venv\Scripts\python.exe scripts/download_asr_model.py --model small
```

模型下载仅访问官方模型仓库，不上传会议资料。转写时只读取已有缓存，不自动联网下载；原始录音与模型缓存默认位于被 Git 忽略的 `data/`。

可在 `.env` 中设置 `ASR_MODEL`、`ASR_DEVICE`、`ASR_COMPUTE_TYPE`、`ASR_LANGUAGE`。默认 `small / cpu / int8 / zh`。英文设为 `en`；语言留空让模型自动检测。GPU 使用前需检查匹配的运行库；没有承诺 GPU 可直接使用。热词表 `hotwords.csv` 目前只作为 ASR 初始提示，不自动替换型号或数字。

说话人分离为独立可选依赖。如果需要自动分离，准备 `pyannote.audio` 4.x 及完整本地 community-1 模型目录，并配置 `DIARIZATION_MODEL_DIR`。模型访问条件及准备步骤参见 [官方模型说明](https://huggingface.co/pyannote/speaker-diarization-community-1)；应用不会替你接受条款或索取 token。推理只加载本地目录，并关闭模型库遥测。缺少组件时仍可转写、回听并人工标注说话人。

同一转写片段包含多人发言、重叠或覆盖不足时，系统保留未知归属，不强行选一个人。在“会议信息与说话人”中补充人员并修正对应段落。匿名标签不等于真实姓名。

音频默认从**首次正式确认**起保留 7 天，也可选择确认后立即删除或持续保留。到期清理在应用启动或页面操作时执行；删除影响所有历史修订的回听，文字证据和纪要不删除。未正式确认的会议不自动过期。

长音频可以转写；若文字超过 12,000 字符或 300 段，目前仍需要拆分后分别整理，不会截断。重新转写生成新草稿，旧版本保留；失败不会将半份转写当成成功结果。

## 测试与开发

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/export_schema.py
.\.venv\Scripts\python.exe scripts/run_eval.py examples/evaluation-format.json
```

最后一个命令只展示虚构数据的计分格式，不能作为模型质量报告。真实评测文件放 `private/`，人工先标出同类别一对一匹配（条件、数值、归属有误不得记为匹配）及幻觉条目，然后运行计分。分母为 0 输出 `null`（N/A）。CER 按 NFKC、忽略大小写/空白/标点进行归一化，型号等关键实体另行人工检查。

目录说明：`minutes/` 为业务模块，`minutes/audio/` 为可选音频模块，`schema/` 为生成的 JSON Schema，`tests/` 为自动化测试，`examples/` 仅含虚构示例，`data/` 为默认个人数据目录。真实资料、录音、数据库、密钥及输出目录已通过 `.gitignore` 排除。只安装文本依赖时，实际解码测试会跳过；交付 v0.2.0 时已安装音频依赖并执行这些测试。

每次完成修改，更新相关测试、验证通过后提交 Git；本项目规则见 `AGENTS.md`。
